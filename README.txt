Repository Structure:
	Data: Contains the Artemis and Addressable datasets.
	Main.ipynb: Data processing code.
	Results: Contains the computed output files generated by Main.ipynb.
	Figures.ipynb: Code for generating the visualizations.
	Labels_Set: Contains the custodial and Sybil wallet labels.

Required Packages: pandas, numpy, polars, matplotlib

Running the Code:
Please run Main.ipynb first. This notebook processes the data and generates the output files in the Results.
Afterward, run Figures.ipynb to generate the visualizations using the output files created in Results.
