# Quantifying Inequality and Mobility in Blockchain Networks
This repository contains the code and results for our project on quantifying inequality and mobility in blockchain networks.
For more details about the project, see our [Working Paper](https://papers.ssrn.com/sol3/papers.cfm?abstract_id=5540258).

## Repository Structure
* `Data/`
  * `Artemis_Data/` — Artemis dataset files.
  * `Addressable_Data/` — Addressable dataset files.
* `Main.ipynb` — Processes the data and generates the CSV files in `Results/`.
* `Results/` — Contains the CSV files generated by `Main.ipynb`.
* `Figures.ipynb` — Uses the CSV files in `Results/` to generate the figures.
* `Labels_Set/` — Contains the custodial and Sybil addresses.

## Required Packages
* pandas
* numpy
* polars
* matplotlib

## Running the Code
`Main.ipynb` should be run first. It processes the raw datasets and generates the CSV files in `Results/`. These files are then used by `Figures.ipynb` to generate the figures.
The datasets are not included in this repository due to their large size. Therefore, `Main.ipynb` cannot be run with the data provided here. If you would like access to the datasets, please contact us.
The CSV files generated by `Main.ipynb` are already provided in `Results/`, so `Figures.ipynb` can be run directly to reproduce the figures.
